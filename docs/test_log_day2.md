## 发现的问题与改进项

1. **Q7 数值幻觉**（钻径 2200→应为 2000 mm）：唯一一处错误，出现在长回复的参数表中。
   - 短期：提示词追加"表格中每个数值必须逐字摘自检索内容，禁止凭记忆填表"
   - 根治：Day 3-4 Python 版用 CSV 结构化查询，参数永不过 LLM 生成
2. **推荐未优先重点型号**（Q3 选了油缸加压老型号 ZR300L 而非 R 系列）：提示词可加"满足条件时优先推荐 Key model: yes 型号"
3. 历史教训见 docs/dify_config.md 踩坑记录（经济索引失效、草稿不持久、分段截断）
