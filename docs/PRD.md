# PRD — 中联重科旋挖钻机 AI 销售助手（v0）

> Zoomlion Rotary Drilling Rig AI Sales Assistant
> 版本：v0（7 天冲刺作品集版）｜ 日期：2026-06-12 ｜ 作者：销售工程师转型 AI PM 项目

## 1. 背景

中东市场旋挖钻机销售依赖分散在 Excel、PDF、宣传册中的产品资料。销售人员面对客户询盘时需要快速、准确地回答参数问题并给出选型建议，但通用 LLM 或粗糙的"PDF 扔进知识库"方案会产生参数幻觉（实测复现过：钻深 56/70 被编成 78/100、钻径 2000 被编成 2200）。**对工程机械销售而言，一个错误的参数可能导致错误的设备选型和真金白银的损失，准确性是底线而非加分项。**

## 2. 目标用户

中联重科旋挖钻机海外销售人员（中东市场为主），非技术背景，工作语言为英语/阿拉伯语，面向客户的响应时间以分钟计。

## 3. 业务痛点

| 痛点 | 现状 | 代价 |
|---|---|---|
| 参数查询慢 | 翻 Excel/宣传册逐行找 | 客户等待，专业形象受损 |
| 参数答错 | 凭记忆或问同事 | 错误选型、商务风险 |
| 选型靠经验 | 老销售经验不可复制 | 新人成长慢，答复不一致 |
| 多语言回复费时 | 手写英文再求人翻阿语 | 响应慢、术语不统一 |

## 4. 用户场景

1. **参数速查**：客户问"ZR255R 最大钻深多少"→ 30 秒内给出带来源的准确答案
2. **型号对比**：客户在 ZR185R 与 ZR255R 之间犹豫 → 并列参数表+差异解释
3. **需求选型**：客户报出"60m 深、2000mm 桩径"→ 推荐 1-3 个达标型号+理由+风险提示
4. **客户回复**：生成可直接发送的英语/阿语专业回复
5. **边界把守**：客户问价格/油耗/质保 → 明确告知资料无此数据，转人工

## 5. 产品目标

- 参数回答准确率 ≥ 90%、单位准确率 100%、来源展示 100%、拒答正确率 ≥ 80%（v0 实测全部 100%）
- 销售从"查资料"到"可发送回复"的时间从 ~15 分钟降至 <1 分钟

## 6. 功能范围

**v0 做**：参数查询（中英文自由文本+下拉）、型号对比、选型推荐、英/阿回复生成、来源追溯、缺数据拒答。
**v0 不做**：价格报价、工程最终适配结论（仅销售参考）、CRM 集成、多品类、语音、移动端。

## 7. 核心流程

```
用户提问 → 型号识别 + 字段识别（结构化匹配）
  ├─ 命中参数字段 → CSV 精确查询 → 值+单位+来源+置信度
  ├─ 选型需求 → 结构化筛选（钻深/钻径达标）→ 排序（重点型号>标准配置>余量小）→ 推荐卡
  │     └─ 生成回复 → LLM 措辞（数字只能来自结构化 facts）/ 模板兜底
  └─ 未命中（价格/油耗/未知型号）→ 友好拒答 + 列出可查项
```

## 8. 数据策略（本项目的核心设计）

1. **第一事实源**：Excel 参数表清洗为 `rotary_rig_master.csv`（15 型号 × 34 字段，每值带 source_file/source_sheet/data_version）
2. **字段字典**：`rotary_rig_field_dictionary.csv` 唯一定义单位与中英文名，生成阶段禁止换算单位
3. **组合值保真**：56/70 这类机锁杆/摩阻杆配置值原样保留并解释，不拆解
4. **N/A 保真**：原表缺失标记原样保留，查询返回 not_available 而非编造
5. **PDF/图片等非结构化资料**：只用于卖点/场景解释（v1 计划），永不作为参数来源

## 9. 架构（两版对照，详见 architecture.md）

- **Dify 原型版**（Day 2）：知识库 RAG（15 张型号事实卡，混合检索）+ 系统提示词约束。优点：搭建快、有引用；局限：长回复中 LLM 仍可能产生数值幻觉（实测 1/23 数值出错）
- **Python 结构化版**（Day 3-5，主推）：参数路径完全不经过 LLM——查询/对比/推荐均为 CSV 结构化计算；LLM 仅在"客户回复措辞"环节使用且被约束只能引用结构化 facts，失败自动降级确定性模板。**数值幻觉被架构消除，而非被提示词缓解**

## 10. 准确性与风控

| 风险 | 对策 |
|---|---|
| 参数幻觉 | 参数路径零 LLM；回复环节数字注入自结构化层 |
| 单位错乱 | 单位唯一定义在字段字典，禁止运行时换算 |
| 过度承诺 | 选型输出强制"仅供销售参考，需工程师确认"；LLM 提示词禁止价格/交期/质保承诺 |
| 静默故障 | LLM 调用失败降级模板并在 UI 披露原因（如 402 余额不足） |
| 回归劣化 | 30 题自动评测管线（run_eval.py），评分基准运行时取自主表，全达标退出码 0 |

## 11. 指标体系

| 指标 | 定义 | v0 实测 | 目标 |
|---|---|---|---|
| 参数准确率 | 回答值与主表逐字一致 | 15/15 = 100% | ≥90% |
| 单位准确率 | 单位与字段字典一致 | 15/15 = 100% | 100% |
| 拒答正确率 | 无数据问题正确拒答 | 5/5 = 100% | ≥80% |
| 来源展示率 | 回答带来源三件套 | 15/15 = 100% | 100% |
| 推荐正确率 | 推荐型号全部达标且排序合规 | 5/5 = 100% | ≥80% |
| 回复合格率 | 回复含正确数字+免责声明 | 5/5 = 100% | 100% |
